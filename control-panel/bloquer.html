Diagnóstico Técnico y Refactorización

Análisis TC-13

El problema no era tu lógica, sino el lugar donde buscabas los elementos. En el Carrito, el mundo cambia.

1. El Choque de Contextos

Tu método removeProductCart fallaba porque usabas .inventory_item como padre. Ese contenedor no existe en la página del carrito.

En el carrito (/cart.html), el contenedor se llama: .cart_item.

2. Integrando el Botón

Para añadir el botón "Continue Shopping" al POM sin errores, debes seguir estos dos pasos:

  • Declarar el readonly continueShoppingButton: Locator;
  • Inicializarlo en el constructor: this.continueShoppingButton = page.locator('[data-test="continue-shopping"]');

Frecuencia de Error en TC-13

Contexto de página incorrecto: El mayor culpable.

Solución en el POM

// En la clase ProductPage.ts
async continueShopping() {
  await this.continueShoppingButton.click();
}

// Corrección del método de remoción
async removeProductCart(productName: string) {
  const container = this.page.locator(".cart_item", { hasText: productName });
  await container.getByRole('button', { name: 'Remove' }).click();
}
